# 大學生租屋完全指南｜Student Rental Guide

本專案以「大學生租屋完全指南：從找房、簽約到入住」為主題，整理台灣租屋相關官方資料，建立可瀏覽的知識 Wiki，並轉換為初學者教學簡報。

## 成果入口

- **教學 HTML 簡報**：部署完成後可由 [GitHub Pages](https://chihyu1003.github.io/student-rental-guide/) 瀏覽。
- **LLM Wiki**：請參閱 [wiki/](./wiki/) 資料夾（包含索引、主題文章與修改紀錄）。
- **原始資料與查核**：請參閱 [raw/](./raw/) 資料夾。

## 專案內容

- `raw/`：五份官方資料整理稿及來源查核紀錄。
- `wiki/`：Obsidian 相容的 Markdown 知識庫，含 YAML metadata、內部連結與 changelog。
- `index.html`：單檔式互動教學簡報，內嵌 CSS 與 JavaScript。

## 使用提醒

本專案為課程教學成果，內容整理以資料蒐集時的官方來源為基礎，不構成個案法律意見。租屋前請再次核對主管機關最新公告、法規版本及個別契約內容。
